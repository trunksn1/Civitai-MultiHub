NAME
MultiHub for Civitai - Unofficial

SUMMARY
Combine selected Civitai creators, models, versions, and public image collections into focused media feeds.

CATEGORY
Photos, Music & Videos

DESCRIPTION
Build one focused Civitai media feed from the creators, models, model versions, and public image collections you choose.

Key features:
• Combine several sources in one continuously loaded feed.
• Keep separate hubs for different projects or interests.
• Sort and filter media, group posts, hide viewed items, and hide creators.
• Add a creator, model, or public image collection directly from its Civitai page.
• Search creators, models, and public image collections with category-aware autocomplete.
• On civitai.red, optionally save a per-hub content profile that is applied when that hub opens.
• View generation details and comments, then perform explicitly requested Civitai actions.
• Keep the resource-saving single-video autoplay default, or opt into playing every video that is at least 15% visible.
• Export and import hubs without exporting API keys, viewed history, or saved Civitai.red profiles
  unless those profiles are explicitly included.

This Firefox Add-ons edition works on civitai.com and civitai.red. Civitai.com serves the SFW range; civitai.red can expose the browsing levels selected in the user's Civitai account, including mature content.

Some account-backed features use the Civitai session already open in Firefox. An optional, revocable Civitai API key can be used for reactions and as a fallback for account-backed features. Requests go directly from Firefox to Civitai over HTTPS. MultiHub has no analytics, advertising, or developer-operated application server.

Requested access:
• Browser storage keeps hubs and preferences locally.
• civitai.com and civitai.red access adds the MultiHub interface, loads the selected feeds, and performs actions the user requests.

MultiHub is an independent, unofficial project and is not affiliated with or endorsed by Civitai.
